# AssetStudio v2.0.0-alpha.1

First native Rust prerelease, focused on **Facepunch Rust** asset browsing and
model export. The original C# implementation remains in the repository as a
reference; the downloadable applications run without .NET or the old helper DLLs.

## Included

- Windows x64 desktop app (`AssetStudio.exe`) and CLI (`AssetStudioCLI.exe`).
- Simple dark interface, operation progress, searchable multi-type filters,
  faster folder loading, and a virtualized asset list and scene hierarchy.
- Mesh-to-hierarchy navigation, checkable subtrees, and split FBX exports with
  textures, skins, and supported animations.
- Standalone **AssetStudio Rust Bridge 0.1.1** for Blender 5.3 or newer, included
  as `assetstudio_bridge.zip`. It bundles the copied Rust shader node and does
  not depend on Rust Toolset or Ruster.

## Use with Blender

1. Extract the Windows package and run `AssetStudio.exe`.
2. In Blender Preferences → Get Extensions → Install from Disk, install
   `assetstudio_bridge.zip` and enable it.
3. Open the complete Rust asset folder using the **Normal** profile. Tick model
   roots in Scene hierarchy, then click **Export to Blender** in the top toolbar.
4. Keep Blender in Object Mode while receiving imports.

The bridge wires Unity material properties, packed alpha, colour spaces, and UV
transforms into the bundled shader. Missing companion maps are searched across
loaded Texture2D assets. Ambiguous matches are reported rather than assigned.

## Validation and limits

Local Windows validation passed 1,035 Rust tests and 40 Python tests, strict
Clippy, formatting, packaging, and native smoke checks. Factory Blender imported
the DragonLauncher viewmodel with ten meshes, 48,072 vertices, one armature,
eight materials, and 29 texture nodes, with repeat imports and failure rollback
verified. These sampled checks do not establish compatibility with every asset.

This is an **alpha**, not full parity with every game-specific path of the old
application. Texture recovery requires the relevant bundles to be loaded and
recognizable names; unsupported game/profile and animation cases remain documented
in the included compatibility guides. Imported textures refer to retained local
export packages; pack Blender's external resources before moving the .blend.

The release contains the Windows package and its SHA-256 checksum. Builds and
verification downloads use temporary runner disk only: **no GitHub Actions
artifacts or caches are uploaded**.
